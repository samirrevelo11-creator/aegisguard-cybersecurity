Sección 1: Marco Conceptual, Política Corporativa y Legislación

1.1 Propósito del Protocolo de Ciberseguridad

El presente documento constituye el estándar normativo, técnico y operativo de carácter estricto para AegisGuard Cybersecurity. Su objetivo fundamental es definir la arquitectura de defensa en profundidad, establecer las reglas de flujo de datos y estandarizar la capacidad de respuesta ante incidentes para proteger la Triada CID (Confidencialidad, Integridad y Disponibilidad) de nuestros activos de información.

1.2 Cumplimiento Normativo Colombiano

Ley 1273 de 2009

Protección de la Información y Delitos Informáticos.

Nuestra arquitectura previene el Acceso Abusivo (Art. 269A) y el Daño Informático (Art. 269D). El SIEM centralizado preserva los logs garantizando la cadena de custodia probatoria.

Ley 1581 de 2012

Protección de Datos Personales (Habeas Data).

Cumplimos aislando la VLAN de Bases de Datos con encriptación fuerte: TLS 1.3 para tránsito y AES-256 para reposo.

CONPES 3854 / 3995

Política Nacional de Seguridad Digital.

Implementamos un modelo de resiliencia operativa y un flujo de notificación temprana de vulnerabilidades ante el ColCERT.

Sección 2: Arquitectura de Red y Diagramación Técnica

Diagrama 1: Arquitectura Física y Lógica de Red

Justificación Técnica del Posicionamiento:

  • Segmentación por Zonas: Separación estricta entre WAN, DMZ, LAN Interna y VLAN de Gestión.
  • Firewall Perimetral: Ubicado en la frontera con el ISP para mitigar DDoS y bloquear IPs externas de alto riesgo.
  • NGFW Interno: Inspección Profunda de Paquetes (DPI) e IPS/IDS justo antes de que el tráfico llegue a los equipos internos.
  • VLAN Aislada: El SIEM se aísla mediante ACLs para que un atacante en la LAN no pueda borrar los logs.

Diagrama 2: Flujo de Datos e Inspección de Tráfico

Secuencia de Inspección y Filtrado:

  • Filtrado WAF DMZ: Intercepta el tráfico web para buscar inyecciones SQL o XSS (OWASP Top 10).
  • IPS NGFW: Identifica dominios y patrones de malware o firmas de red anómalas.
  • EDR Endpoint: Si el malware llega al PC, evalúa el comportamiento en RAM (intento de cifrado) y aísla la red automáticamente.

Sección 5: Simulacro de Ataque (Ransomware)

1. Vector (Phishing)

Empleado ejecuta archivo adjunto PDF malicioso, iniciando script oculto en segundo plano.

2. Detección EDR

El agente detecta escritura criptográfica anómala en RAM y suspende el proceso PID:4492.

3. Bloqueo C2 (NGFW)

NGFW bloquea salida TCP hacia el servidor Comando y Control basado en base de firmas de IPS.

4. Aislamiento

El EDR desconecta la interfaz de red lógica del equipo para evitar movimiento lateral en la LAN.

5. Forense y Recuperación

El SIEM guarda evidencia de logs para la cadena de custodia. TI formatea y restaura desde backup.
